# General audit, 2026-11-09

This audit compares the current repository with `prompt-bieltructor-v2 10.33.53.md`. Earlier notes describing lighting, tool wear, lava and the input module as missing are outdated: these systems are implemented. Passing tests does not prove 100% reliability.

## Corrections

- Moving tools into/out of chests, emptying a chest and collecting a recovery backpack preserve durability. Previously these paths silently repaired tools.
- Breaking a chest or furnace now checks capacity atomically. If its contents do not fit, the container and backpack stay intact and the existing full-backpack message appears. Previously excess items disappeared.
- Imported recovery backpacks validate item identifiers, stack counts and wear; furnace outputs reject unknown items.
- Cloud synchronization rejects corrupt or duplicate remote entries instead of interpreting them as absent worlds and uploading over them.
- Failed conflict uploads retain the conflict for retry, report unavailability and do not mark the world as synchronized. Repeated clicks, disabled sync and active gameplay are guarded.
- Null sync metadata and native bridge exceptions are recoverable. Native request timeout callbacks are cancelled after replies.
- Removed external navigation from the game credits, matching the offline child-facing brief; removed the now-unused native external-link/popup handlers and UI delegate wiring. Credits remain visible as plain text.
- README no longer claims both partial completion and complete implementation.

## Review scope and cleanup

Reviewed the current source/module inventory, inventory and crafting rules, save validation, synchronization, container/recovery integration, input declarations, native bridges, build scripts, CI configuration and the existing phase-by-phase implementation record. They were retained.

## Follow-up (same day)

- **iCloud compare-and-write:** every save carries the `updatedAt` the game saw when listing, or null for a new file. `CloudBridge.swift` reads and writes inside one `NSFileCoordinator` write and refuses with `{ ok: false, changed: true }` if the file changed; the game retries a few seconds later instead of reporting a failure.
- **iCloud deletion:** deleting a world writes a marker (`{ id, deleted: true, updatedAt }`) instead of removing the file. Other devices delete their copy if they have not played it since the last sync, and keep it and send it back up if they have. A deletion made offline is remembered (`biel-deleted`) and finished on a later sync. The unused native `delete` action was removed.
- **World list:** every world can be renamed and exported from the list, not only the open one.
- **Compass and map items** (listed among the brief's items): the compass says how far home is and in which direction; the map opens the island map.
- **Dead code:** a full pass (exports, strings, CSS classes, Swift) found only one export used nowhere else (`HUNT`), now private.

Validation: 125 Node tests and 194 Mac smoke checks passed; XCUITest passed on iPad Pro 11-inch, iPhone 17e and iPhone 17 Pro Max simulators. The new cloud rules are tested with two pretend devices sharing one folder (`tests/persistence.test.js`) and in the smoke suite. Two real devices with a real iCloud account have not been tried.

## Second follow-up (same day): pause menu and key beeps

- **Pause menu:** "Main menu" and "Quit" used the borderless "quiet" style, and with ten choices the panel scrolled in an 800-pixel window. The other choices now sit in two columns, every button has a border and the menu fits without scrolling. One column is used on narrow phones.
- **Key beeps on the Mac:** keys the page did not mark as handled (W, A, S, D, numbers, F...) reached the window, and macOS played its alert sound on every press. While playing, every key except ⌘ and Ctrl shortcuts is now marked as handled, and the Mac window (`GameWindow`) no longer beeps for unhandled keys.
- **Footsteps:** quieter and a little less frequent.
